# VideoTools Pro

Responsive static website starter.

## Working features
- Image compressor: JPG/PNG/WebP input; outputs JPEG or WebP in-browser.
- Local video preview and basic file details.
- Mobile responsive design and basic SEO metadata.

## Not built yet
Direct TikTok/Instagram downloading, server-side video conversion, video-to-MP3, advanced trimming and GIF export. These require additional engineering and must respect copyright and platform terms. The current site does not claim those features work.

## Free hosting
Upload these files to a GitHub repository and enable GitHub Pages, or deploy the folder to Cloudflare Pages. Replace `YOUR-SITE-URL` in robots.txt and sitemap.xml after the site has a public address.
